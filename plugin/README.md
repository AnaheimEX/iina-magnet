# PikPak + Mikan for IINA

Version 1.1.0 · Official IINA 1.5 · macOS 14+ · Apple Silicon

This unofficial plugin opens separate native windows for the complete Mikan
website and PikPak drive. It bundles `IINA Cloud.app`; the IINA player itself is
not modified. Install the `.iinaplgz` package through IINA Settings → Plugins,
allow its file-system permission and open PikPak or Mikan from the plugin menu.

The companion manages web login, Keychain tokens, persistent WebKit state and
save-and-play requests. The plugin manages the playback window, buffering and
explicit system HTTP proxy handoff. No personal credentials or proxy nodes are
included. First launch may need web login or Keychain permission.

This is an ad-hoc signed, unnotarized development build. It has been compiled and
packaged, but real-account playback and performance have not been validated.
